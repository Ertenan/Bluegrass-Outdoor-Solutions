# Bluegrass Outdoor Solutions

Professional landscaping services based in Union, KY. Established in 2023.

Bluegrass Outdoor Solutions provides top-tier landscaping and outdoor maintenance services. We are dedicated to transforming outdoor spaces with quality craftsmanship and attention to detail.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Development

### Installation

```bash
npm install
```

### Running the development server

```bash
npm run dev
```

## Configuration

- **ES Modules:** The project uses `"type": "module"` in `package.json`.
- **Images:** Image optimization is configured to allow `images.unsplash.com`.
- **Logo:** The company logo is located at `public/logo.jpg`.
